# PS1 Generator glossary

## Scope row

One separately described part of the balustrade work in a single PS1/PS3
document. A scope row has one location and one or more selected structure
types. A document may contain up to five scope rows. The initial scope row and
every newly added row begin with no selections.

## Structure type

A work area such as Deck, Balcony, Stair, or Landing. More than one structure
type may be selected within a scope row when they share the same location and
structure-built value, for example `Stair and Balcony`.

## Location

Whether a scope row is Internal or External. The document-level PDF checkboxes
reflect every location represented by its scope rows.

## Structure built

Whether the work covered by the document is New or Existing. It applies to the
whole document, not individual scope rows. It appears once at the beginning of
the generated work description.

## Combined area list

The ordered, human-readable list formed from all scope rows, for example
`Internal Stair and Balcony Area and External Deck Area`. It is used in the
PS3 compact location/area field; the full work description also includes the
glass specification, document-wide structure-built value, and system.

## Pool scope

A Pool Area uses a pool-specific PS1 template and must be the document's only
scope row. It is selectable only when it is the sole area row; selecting it
disables adding further scope rows.
